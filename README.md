# 🚍 Smart Transport Ticket Booking System

A console-based ticket booking and transport management application built in **C**. It enables user registration/authentication, transport search, ticket reservation, and persistent data storage using text files.

---

## 🌟 Key Features

* **User Authentication:** Sign up and login functionality for secure access.
* **Vehicle Management:** Browse available transport routes, schedules, and vehicle details.
* **Ticket Booking:** Reserve and manage seat bookings dynamically.
* **Persistent File Storage:** Data is stored locally across text files (`users.txt`, `vehicles.txt`, `bookings.txt`).

---

```text
